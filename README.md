# 🛒 E-commerce Analysis

## 📌 Project Overview

Welcome to my **E-commerce Analysis Project**! 🚀

This project focuses on analyzing an e-commerce dataset using **MySQL** to discover meaningful business insights. Through SQL queries, I explored product information, pricing patterns, categories, and other important metrics.

The main goal of this project is to practice **SQL data analysis skills** and understand how raw data can be converted into valuable business insights. 📊

---

## 🛠️ Tools & Technologies

🔹 **Database:** MySQL  
🔹 **IDE:** MySQL Workbench  
🔹 **Version Control:** GitHub  

---

## 📂 Dataset Information

📊 The dataset contains **5,000 e-commerce records** with information related to products and sales.

### Dataset includes:

- 🏷️ Product details
- 📦 Categories
- 💰 Product prices
- ⭐ Ratings
- 👥 Customer-related information
- 📈 Sales-related information
